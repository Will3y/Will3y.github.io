# Les missions de Willyam

Petit jeu d'exercices CE1 → CE2 (maths, français, anglais et logique), en un seul fichier : `index.html`.

138 missions (51 en maths, 47 en français, 19 en anglais, 21 en logique), plus une « mission surprise » qui mélange les missions déjà réussies.
En anglais, les mots et les phrases sont prononcés par la voix de l'appareil (synthèse vocale du navigateur, `en-GB`).
Dans l’espace parent : récompenses, étoiles bonus et retraits (bon comportement, effort, règle non respectée…), temps de jeu par jour, longueur des missions (5, 8 ou 10 questions), code parent, sauvegarde.

- En ligne : https://will3y.github.io/willyam/
- Hors ligne : `index.html` s'ouvre aussi en double-clic, sans rien d'autre.
- Sur iPhone : Safari → Partager → « Sur l'écran d'accueil ». Ensuite l'icône marche sans Internet (grâce à `sw.js`).

Fichiers en plus de `index.html` (utiles seulement pour la version en ligne) :
`manifest.webmanifest` (nom et icône sur l'écran d'accueil), `sw.js` (hors ligne), `img/` (icônes).

La progression reste sur chaque appareil (localStorage). Pour la transférer :
Espace parent → Sauvegarde → « Copier le code » ou « Enregistrer un fichier », puis « Importer » sur l'autre appareil.
